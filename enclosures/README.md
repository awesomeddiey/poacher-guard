# 3D-printable cases

Parametric cases for the two ESP32 devices. Everything is generated by `make_enclosures.py`, so you can change any size and re-run:

```
pip install trimesh manifold3d numpy
python make_enclosures.py        # writes stl/*.stl and report.json (checks every mesh is watertight)
node render_previews.js          # optional, previews/*.png (needs playwright and a copy of three.js)
```

| Part | Files in `stl/` | Overall size (mm), including ears and hood |
|---|---|---|
| Flame node: base | `flame_node_base.stl` | 91.3 x 72.3 x 24.5 (box body 63.3 x 63.3) |
| Flame node: lid | `flame_node_lid_print_orientation.stl` | 67.5 x 67.5 x 12.5 |
| Ranger tag: base | `ranger_tag_base.stl` | 86.8 x 29.2 x 16.4 (box body 66.8 x 29.2) |
| Ranger tag: lid | `ranger_tag_lid_print_orientation.stl` | 71 x 33 x 8.4 |

`*_lid.stl` is the lid as assembled (top up). Print the `*_print_orientation.stl` version, which is flipped so the flat top lies on the bed.

## What is inside

**Flame node** (weatherproof, wall or post mounted)
* ESP32 DevKit V1 (30 pin, 51.5 x 28.5 mm, pins down) on four corner blocks, USB end at the back wall, with a 14 x 9 mm cable slot.
* 4-pin flame sensor module (32 x 14 mm, sensor pointing forward) on one screw post, sensor behind a 10 mm window with a 9 mm sun hood.
* Lid with a rain skirt that overlaps the walls, four M3 screws, two ribs that hold the ESP32 down, two wall-mount ears (5 mm holes).

**Ranger tag** (clip on, sew into a pocket or hang on a lanyard)
* 502030 LiPo cell (30 x 20 x 5 mm) lies on the floor. An ESP32-C3 SuperMini and a TP4056 charger board each rest on one end block and on the battery (stick with double-sided foam tape). USB-C openings in both end walls. Lanyard ears (4.5 mm holes).
* The firmware in `firmware/ranger_tag` runs on the C3 as well; use `BLEDevice` from the ESP32 Arduino core 2.0 or later.

## Check these before you print (measure with callipers)

The sizes are for the common boards named above. Boards from different makers differ by a millimetre or two. Edit the `PARAMETERS` block at the top of `make_enclosures.py` for: `ESP` (length, width, pin height), `FLAME` (module size, sensor height), `C3`, `TP`, `LIPO`. Do a quick test print of the base only and drop the real boards in before printing the lid and the rest.
Flame modules vary most. If your sensor head stands upright instead of pointing forward, raise `FLAME["sensor_z"]` or make the window taller.

## Printing

| Setting | Flame node (outdoors) | Ranger tag |
|---|---|---|
| Material | PETG or ASA (PLA softens in a hot car or in the sun) | PETG or PLA |
| Layer height | 0.2 mm | 0.2 mm |
| Walls / top / bottom | 3 / 4 / 4 | 3 / 4 / 4 |
| Infill | 25 % gyroid | 20 % |
| Orientation | base open side up, lid in print orientation | same |
| Supports | none, except the sensor hood: enable "touching build plate" or print the hood a little wider | none |

## Assembly

1. Test fit the boards, then fix the flame module with one M3 x 6 self-tapping screw and the ESP32 with a drop of hot glue on one block.
2. Run the USB lead through the slot and seal the slot with silicone or a rubber grommet. Add a small silica gel sachet before closing.
3. Put a strip of 2 mm foam or a bead of silicone on the wall tops, set the lid on and fit four M3 x 10 self-tapping screws.
4. Mount the flame node with the hood facing the area to watch and tilted slightly down so rain runs off. Keep it out of direct sunlight, because the sun gives false fire readings on infrared flame sensors.
5. Keep metal and wet bodies away from the BLE tag. A tag against the body or under a thick pack can read 10 to 20 dB weaker, so re-check the RSSI limit in `config.yaml` after fitting.

This is a first design. A printed case is splash resistant, not waterproof, until it is sealed. Expect to adjust it once after a test print.
