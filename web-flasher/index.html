Install the Poacher Guard sensor node

Writes the node program to an ESP32 (38-pin DevKit) straight from this page. About one minute.

  1. Use Chrome or Edge on a computer (not a phone).
  2. Plug the ESP32 into this computer with a USB data cable. Close the Arduino IDE and Serial Monitor.
  3. Click Install, pick the port named CP210x, CH340 or USB Serial, then click Install again.
This browser cannot do it. Open this page in Chrome or Edge on a computer. Not allowed here. Open this page directly (https), not inside another page.

If it waits at "Connecting": hold the BOOT button on the ESP32 until it starts. No port in the list: install the CP210x or CH340 USB driver, or try another cable.

After installing: unplug the ESP32 and power it normally. Start Poacher Guard on the PC, type the phone number in SMS alerts & sensor node, press Save, then Send test SMS. The node connects over Bluetooth by itself.
